下载 Liveglot（macOS 与 Windows 版）

Liveglot 提供原生桌面客户端，同时支持 Apple 芯片 Mac（macOS 14 Sonoma 及以上）与 64 位 Windows 10 / Windows 11 电脑。

macOS 磁盘映像与 Windows 安装包

macOS 版提供已公证的磁盘映像（Liveglot.dmg），打开后将 Liveglot 拖入「应用程序」即可。首次采集系统声音时需在系统设置中授予「屏幕与系统音频录制」权限。

Windows 版提供免管理员权限的用户级安装包（Liveglot-Setup.exe），支持应用内自动更新。系统声采集直接通过 WASAPI Loopback 完成，无需录屏授权。

  • macOS：Liveglot.dmg → 应用程序 → Liveglot.app（macOS 14+，Apple 芯片）
  • Windows：Liveglot-Setup.exe → 用户目录安装（Windows 10/11 64 位）
  • Windows 本地 Whisper 内置 Vulkan 显卡加速，无独显时自动回退 AVX2 CPU

系统要求

macOS 版面向搭载 Apple 芯片的 Mac；Windows 版面向 64 位 Windows 10 或 Windows 11。

  • macOS：Apple 芯片（M 系列），macOS 14 Sonoma 或更高版本
  • Windows：Windows 10 或 Windows 11（64 位 x64；ARM64 可通过系统转译运行）

试用与授权

无需绑卡即可免费试用 7 天。一次购买 $19.99 终身使用，最多可在两台电脑（Mac 或 Windows 任意组合）上激活，也可随时在设置中停用释放名额。

安装后：选择识别与翻译

语音识别可免费使用内置的本机 whisper.cpp 模型，或配置自己的 Soniox 云端 Key。翻译需要填入兼容 OpenAI 的接口与 Key（或本地 Ollama）——Liveglot 不出售翻译额度。

当前设置界面不提供 Apple 原生识别，请选择本地 Whisper 或 Soniox。
