上手教程

从下载到第一堂翻译好的课，大约十分钟，Mac 和 Windows 都可以。不需要任何技术背景：所有设置都在应用里点几下完成。

下载 macOS 版下载 Windows 版

1. 下载并安装

用本页顶部的按钮下载。第一次打开应用时，7 天全功能免费试用自动开始，不需要绑卡。

  1. Mac：打开下载的磁盘映像，把 Liveglot 拖进「应用程序」，再从那里打开。需要 Apple 芯片的 Mac、macOS 14 或更高版本。
  2. Windows：运行 Liveglot-Setup.exe，按安装向导走完即可。只安装给当前用户，不需要管理员密码。Windows 10 或 11（64 位）。

Liveglot 会自动更新：有新版本时会提示你安装，也可以在「设置 → 关于」里手动检查。

2. 让 Liveglot 听到声音

Liveglot 听的是电脑正在播放的声音。它只录声音，从不录屏幕；除非你之后选择了云端服务，否则什么都不会上传。

  1. Mac：第一次点「开始录音」时，macOS 会请求「屏幕与系统录音」权限。系统设置旁会出现一个小引导窗：打开 Liveglot 的开关（或把应用拖进列表），然后在 Liveglot 里点「重启应用」。macOS 要求重启后权限才生效。
  2. Windows：录系统声不需要任何权限。如果你用麦克风而 Windows 拦住了它，Liveglot 会显示一个按钮，直接打开「设置 → 隐私和安全性 → 麦克风」，允许桌面应用访问即可。

3. 下载语音识别模型

把语音转成文字这一步在你自己的电脑上完成，免费，用的是 Liveglot 帮你下载的模型。不用另外安装任何东西。

  1. 打开「设置 → 识别」，「本地模型」已经默认选好。
  2. 在「下载模型」里，点 Large v3 Turbo（约 550 MB）旁边的「下载」。8 GB 内存的电脑建议选更轻的 Small。
  3. 下载期间可以关掉设置窗口，下载完成后模型会自动选好。
  4. 「识别语言」选讲师说的语言（大多数课程是英语），比「自动识别」更快也更准。
  5. 点「保存」。

每次录音的第一句要等几秒钟加载模型，之后就能跟上。Windows 上有显卡时会自动用显卡加速。

更想用云端？Soniox 是付费服务，更快一些、更准一些。在 console.soniox.com 创建 API Key，然后在「设置 → 识别」选择「Soniox 云端」，粘贴 Key，选择项目所在区域，点「测试连接」。

4. 接入翻译服务

翻译和侧边聊天使用 AI 服务，用你自己的 Key，一小时的课通常只要几美分。如果没用过这类服务，OpenAI 或 DeepSeek 都可以，DeepSeek 最便宜。

  1. 打开「设置 → 翻译与聊天」。
  2. 在「快速填写」里点一个服务，接口地址和模型会自动填好。
  3. 点「获取 … 的 API Key →」，在打开的网页登录，创建一个 Key 并复制。
  4. 粘贴到「API Key」。
  5. 「翻译成」选你想读的语言，然后点「测试连接」和「保存」。

想让一切都留在本机？从 ollama.com 安装 Ollama，在里面下载一个模型，然后在「快速填写」里选 Ollama，不需要 Key；但除非电脑够快，否则会慢一些。

5. 让译文念出来（可选）

Liveglot 可以在每句译文出来的瞬间把它念出来，像同声传译一样，用的是在你电脑上运行的自然人声。默认关闭，需要你打开。

  1. 打开「设置 → 配音」，点语音模型旁边的「下载」（约 375 MB，支持中文和英文）。
  2. 下载完成后，打开「朗读译文」。
  3. 选一个「音色」，点「试听」听听效果，再调「语速」。配音不会漏掉任何一句：落后于讲师时会自动加快，最快到「落后时的最高语速」，追上后再慢回来。
  4. 如果原声比配音响，调高「音量」。点「保存」。

录音时标题栏会出现一个「配音」标签，表示正在朗读；点一下静音，再点恢复。

想听得清楚，有几个小技巧：

  1. 音源里有麦克风时请戴耳机，否则配音会被麦克风录进去。
  2. 与其把配音调大，不如把原声调小。播放器自带音量条的（YouTube、Zoom、大多数视频播放器）直接拉低。GoTo 这类网络研讨会页面往往没有音量条：给浏览器装一个按标签页调音量的扩展，比如 Chrome 的 Volume Master，只把那个标签页调低。Liveglot 照样能听到它。
  3. Liveglot 自己的配音不会被识别回去：Mac 上如此，Windows 10 2004 及更新版本也如此。更老的 Windows 上配音可能被再次识别成字幕，此时把配音音量调低或戴耳机。

6. 告诉它这堂课讲什么（可选）

用一两句话交代主题、讲师，或你预计会出现的行话——股票代码、缩写、产品名——识别、翻译和聊天对专业词汇的准确度会明显提高。

  1. 在主界面「场景背景」旁点「管理…」，再点「+ 新增预设」。
  2. 起个名字，用一两句话描述这堂课，点「保存」。
  3. 开始录音前选上这个预设，它会随本场记录一起保存。

7. 开始第一场

  1. 在电脑上播放网课或直播。
  2. 在 Liveglot 里选择音源：电脑里播放的内容选「系统声」，现场选「麦克风」，或两者同时。
  3. 点「开始录音」。字幕先出现，译文逐句跟上——如果打开了配音，声音也会跟上。
  4. 点一句字幕可以在侧边聊天里追问，右键可以复制。
  5. 下课后点「停止」。每一场都会以 Markdown 文件保存在「文稿/Liveglot」（可在「设置 → 记录」里改文件夹）。

8. 激活授权

试用结束后，在本网站一次性购买授权，$19.99。付款后的页面会显示授权码，也会发到你的邮箱。

  1. 打开「设置 → 授权」。
  2. 粘贴授权码，点「激活」。

一个授权码可在两台电脑上使用，Mac 或 Windows 任意搭配。想换到另一台，先在旧电脑上点「停用」。
